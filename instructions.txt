Lab 2: Lane Keeping Assistance (LTA) Simulation

Project Description:
This project simulates a Lane Keeping Assistance (LTA) system for a vehicle driving on a highway. 

1. Prerequisites:
- Python 3.9+
- Required libraries are listed in the "requirements.txt" file.
- Keyboard or Joystick (tested with a PlayStation gamepad, but most wired controllers should work!)


2. Setting Up Python:
If Python 3.9+ is not installed, follow these steps:

   - macOS/Linux:
     1. Check if Python 3 is already installed, run this command on terminal:
        "python3 --version"
     2. If not installed, download and install it from [Python's official website](https://www.python.org/).

   - Windows:
     1. Download the Python 3.9+ installer from [Python's official website](https://www.python.org/).
     2. During installation, check the box "Add Python to PATH".
     3. Verify the installation:
        "python --version"

3. Preparing the Environment:
   - Update Pip (optional but recommended):
     Run the following command to ensure pip is up-to-date:
     "python3 -m pip install --upgrade pip"

   - Install Dependencies:
     Install the libraries listed in "requirements.txt":
     "python3 -m pip install -r requirements.txt"

4. Running the Simulations:
Two simulations are provided:
   1. Without LTA: The car is manually controlled by the user via joystick or keyboard.
   2. With LTA: The car benefits from an active Lane Keeping Assistance system that automatically adjusts the steering to keep the vehicle within the lane.

Run the simulations as follows:
   - Without LTA (Manual Control): 
     python3 task_3_4_wheels.py
   - With LTA (Lane Assistance Active):
     python3 task5_7_lta.py

Controls:
- Keyboard: Left Arrow (steer left), Right Arrow (steer right).
- Joystick: Use the left stick to steer.
