Lab 2: Lane Keeping Assistance (LTA) Simulation

Project Description:
This project simulates a Lane Keeping Assistance (LTA) system for a vehicle driving on a highway. 

1. Prerequisites:
- Python 3.9+
- Required libraries are listed in the "requirements.txt" file.
- Keyboard or Joystick (tested with a PlayStation gamepad, but most wired controllers should work!)


2. Instructions:
Place all project files in the same directory.
Note: Ensure the car sprite image (tesla-birdview.png) is in the same directory as the main scripts.

Install dependencies using the "requirements.txt" file. Run the following command in the terminal:
   python3 -m pip install -r requirements.txt


3. Running the Simulations:
Two simulations are provided:
   1. Without LTA: The car is manually controlled by the user via joystick or keyboard.
   2. With LTA: The car benefits from an active Lane Keeping Assistance system that automatically adjusts the steering to keep the vehicle within the lane.

Run the simulations as follows:
   - Without LTA (Manual Control): 
     python3 task_3_4_wheels.py
   - With LTA (Lane Assistance Active):
     python3 task5_7_lta.py

Controls:
- Keyboard: Left Arrow (steer left), Right Arrow (steer right).
- Joystick: Use the left stick to steer.
